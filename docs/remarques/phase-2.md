# Remarques de la propriétaire : phase 2

## Itération 1 (reçues le 2026-10-16)

Reproduites mot pour mot.

1. Retire l'option "réduire les animations"
2. Quand on clique sur "Créer une partie", on sélectionne le code de la partie parmi la liste, puis on valide. Ensuite on arrive dans la salle d'attente, où s'affiche discrètement le code de la partie, puis le menu de sélection emblème/nom, et en-dessous la liste des participantes.
3. Quand on clique sur "Rejoindre une partie", on doit rentrer le code de la partie. Quand c'est fait, on arrive sur la salle d'attente, où s'affiche discrètement le code de la partie, puis le menu de sélection emblème/nom, et en-dessous la liste des participantes.
